ECE467 · Fall 2026 · Jianwen Zhu

Overview

Compilers are more ubiquitous than most programmers realize. Their ideas power browser scripts, database queries, and the tensor computations behind language models. ECE467 reveals the machinery behind operations you have taken for granted: how a system understands a program and turns it into work a machine can execute.

You will follow that journey from source text to executable code: recognizing tokens and grammatical structure, resolving names and checking types, representing and analyzing programs, and generating efficient instructions. You will learn how runtime storage supports function calls and how optimizations change a program while preserving its meaning. Together, these ideas explain the connection between the code you write and its behavior on the hardware.

Building a compiler also develops the art of programming — choosing representations and interfaces that make complex software manageable — and the science of programming — turning formal models into working algorithms. These benefits extend well beyond compiler development.

The project brings this foundation to the frontier of AI infrastructure. You build a compiler for a language that operates on tensors—multidimensional arrays—to express computations used in modern large language models. Your generated programs target graphics processing units (GPUs). You test their results and measure the performance of your optimizations.

Project

Put the lecture material into practice by implementing a compiler in C for ECE467 Tiny Tensor Language (TTL467). The language names tensor dimensions, applies operations to individual elements, and combines values through reductions such as sums. Your compiler emits programs in TileLang, a language for writing GPU kernels. A kernel is a function executed by GPU threads; the supplied tools compile and run these kernels.

The target application is large language model inference: using a trained model to predict the next text token, such as a word or word fragment. Explore the computations behind that prediction in the Model Zoo, from matrix multiplication to attention and a GPT-2 forward pass. The optimization challenge is to make these computations run faster while preserving their results.

Two supporting tools connect your compiler to working hardware. libttl (Tiny Tensor Library) provides the C interface for managing tensors and executing compiled programs. CloudMake runs your project's Make targets locally or on cloud hardware, so you can keep editing locally while building and testing on a GPU.

The project is split into five stages, each implementing one compiler phase. You first recover the program's structure and check its meaning, then generate working code and optimize it. Supplied intermediate files let you test each phase independently before connecting the phases.

01 · Lexical Analysis

Implement a scanner that groups source characters into tokens such as keywords, identifiers, and numbers. Report invalid input and pass the token stream to the parser.

02 · Syntax Analysis

Implement a parser that checks the token stream against TTL467's grammar. Construct an abstract syntax tree representing declarations, expressions, and their relationships.

03 · Semantic Analysis

Resolve names and validate tensor operations. Determine the types and shapes that code generation needs, and diagnose programs that violate the language's rules.

04 · Code Generation

Translate the checked program into TileLang kernels and descriptions of how to connect them. Test the results across the required operations and shapes. Keep this correct, unoptimized version as the baseline for the next stage.

05 · Code Optimization

Choose and implement optimizations in your compiler. Compare against your baseline on common workloads, investigate performance changes, and support your results with reproducible correctness checks and timings. The leaderboard shows performance; the final report explains the compiler decisions behind it.

Lab sessions provide time to implement, test, and discuss your design. The tutorials below prepare you for this work with small programs to run, modify, and diagnose.
