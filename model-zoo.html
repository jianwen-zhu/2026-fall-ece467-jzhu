Model Zoo

Follow tensor programs from a single matrix product to attention and a GPT-2 forward pass—the computation that maps input tokens to scores for possible next tokens. Each entry includes a formatted view of the code and the same source as a raw .ttl file.

These programs use the course language described in the TTL467 reference. Attention and GPT-2 are optional reading examples with small, fixed dimensions. They are separate from the required lab tests and performance benchmarks.

Attention

Attention combines information from different positions in a sequence. Matrix products produce relevance scores, a causal mask excludes future positions, and softmax converts the scores into weights. A second matrix product uses those weights to combine values. Follow how this computation is assembled from tensor operations.

GPT-2 forward pass

Now follow a complete model. Token and position embeddings convert input identifiers into vectors; two transformer layers combine attention with feed-forward computations to produce logits, the scores for possible next tokens. The source makes normalization and residual connections explicit. Its small configuration uses a vocabulary of 32 and a sequence length of 8 so the shapes are easy to follow.
